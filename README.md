#  ShopEase - Multi Vendor E-Commerce Platform

A full-stack **Multi Vendor E-Commerce Platform** built using the **MERN Stack** with separate modules for **Customer**, **Vendor**, and **Admin**.

##  Features

###  Customer
- User Authentication (JWT)
- Browse & Search Products
- Add to Cart & Buy Now
- Checkout
- Order History & Tracking

###  Vendor
- Vendor Dashboard
- Create Store
- Add / Edit / Delete Products
- Manage Orders
- Dashboard Analytics

###  Admin
- Admin Dashboard
- Manage Users
- Manage Products
- Manage Orders
- Role Management

---

##  Tech Stack

**Frontend**
- React.js
- React Router
- Tailwind CSS
- Context API

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

##  Installation

```bash
# Clone Repository
git clone <https://github.com/chandru0777/multi-tenant-ecommerce>

# Backend
cd backend
npm install
npm run dev

# Frontend
cd frontend
cd e-commerce
npm install
npm run dev
```

---

##  Environment Variables

Create a `.env` file inside the `server` folder.

```env
PORT=8000
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
RAZORPAY_KEY_ID=your_razorpay_key
RAZORPAY_KEY_SECRET=your_razorpay_secret
```
